## 这是什么

一幕 YiMu 是一款回归视听本质的个人流媒体播放器，支持 Mac、iPhone、iPad 与 Apple TV（tvOS 17+）。

它不试图成为下一个臃肿的社交流媒体平台，没有信息流推送，没有开屏广告，不收集任何用户隐私。它只是静静待在你的 Dock 栏与主屏幕上，当你打开一段视频、一条电视直播流或 NAS 媒体库时，以极致的性能与克制的界面，呈现那一幕纯粹。

> 一幕之间，纯粹视听。

## 功能亮点

| | 功能 | 说明 |
|---|---|---|
| 🎬 | **全格式硬解** | 基于 MPVKit 原生内核，流畅播放 4K/8K HDR、MKV、MP4、H.265/HEVC、AV1、Dolby Vision |
| 📺 | **电视直播海报墙** | 支持 IPTV M3U/M3U8 播放列表，支持海报墙 (2:3)、网格卡片 (16:9) 与极简列表视图 |
| ⚡ | **极速滑动手势换台** | 屏幕上下/左右滑动手势快速切台、浮动快捷换台钮、台号 OSD 浮动横幅、节目列表抽屉 |
| 🍿 | **海报墙与元数据刮削** | 本地媒体与影视库自动刮削海报、剧照、演职员与评分，支持多选、批量管理与快速搜索 |
| 🔒 | **端到端隐私与钥匙串** | NAS / WebDAV / SMB 访问密码严格锁定于 Apple 本机 Keychain，绝不上传云端，关断外部同步 |
| 📲 | **跨端无缝体验** | 为 Mac (快捷键与窗口悬浮)、iOS (手势与触感反馈)、tvOS (Siri Remote 焦点引擎) 深度原生定制 |
