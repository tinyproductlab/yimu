How to Verify and Test YiMu on macOS

  1. Drag & Drop Playback: Drag and drop any local video file (e.g. .mp4, .mkv, .mov, .avi) directly from macOS Finder into the YiMu application window. Playback starts instantly with hardware acceleration.
  2. Local Folder Scraper & Poster Wall: Click the + button at the top right of the application window to select a folder containing video files. YiMu will automatically parse the media filenames, scrape metadata locally, and organize movies/shows into an elegant poster wall.
  3. Network Streaming (WebDAV / SMB): Click the + button and select "Add Network Media (NAS / WebDAV / SMB)". Input any standard local network streaming address or WebDAV server URL to stream videos directly without full downloads.
  4. Playback Controls & Gestures: During playback, double-click left/right side of the window to seek 10 seconds back/forward; adjust aspect ratio (Original, 16:9, 21:9, Fill Screen); toggle audio tracks; and adjust subtitle delay.
